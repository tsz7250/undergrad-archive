# Intended Use / Problem Definition

## 問題定義 (Problem Definition)
現有的 CSV 檔案查詢工具在處理大量資料時，常因缺乏高效索引與優化查詢機制，導致查詢速度緩慢且難以支援複雜條件。傳統工具多僅支援基礎檢索，對於需要複合條件、即時回應的應用場景，效能與彈性皆有限。

## 預期用途 (Intended Use)
本專案旨在實作一套輕量級的 CSV 小型資料庫與查詢引擎，專為高效能數據檢索設計。系統整合記憶體映射 (Memory-mapped I/O) 與自動化 Hash Index，能即時處理大檔案並支援類 SQL 的複合查詢語法。適用於需要快速查詢大量 CSV 資料、進行資料分析或教學演示資料庫核心邏輯的場景。

## 目標對象 (Target Audience)
本系統適合資料庫系統課程學習者、C++ 工程師、資料分析師，以及任何需要高效 CSV 查詢解決方案的開發者或研究人員。
