# 1121 線性代數課程作業

## 📖 課程概述

此倉庫包含了1121 線性代數課程的所有作業和報告程式碼。

## 🛠️ 使用的程式語言

- **C#** - 用於測量系統和點燈遊戲
- **C++** - 用於ILP問題生成和RREF計算
- **LINGO** - 用於整數線性規劃求解

## 📁 專案結構

| 資料夾 | 描述 |
|-------|-----|
| [**ILP**](./ILP/) | 整數線性規劃 - 圖形二分割問題 |
| [**Measurement**](./Measurement/) | C# 幾何測量系統 |
| [**LightsOutGame**](./LightsOutGame/) | C# 點燈遊戲實作 |
| [**RREF**](./RREF/) | 簡化階梯形矩陣計算器 |

## 🎯 學習目標

通過這些專案，學習並應用：
- 矩陣運算和線性方程組求解
- 幾何計算和測量
- 整數線性規劃建模
- 程式設計實作線性代數概念
