# LineChart - 資料視覺化系統

## 📖 專案描述

使用 Google Charts 製作互動式折線圖的資料視覺化系統。系統能夠讀取並處理 CSV 檔案中的資料，並生成動態的折線圖表。

## ✨ 功能特色

- **CSV 資料處理**: 自動讀取和解析 CSV 格式資料
- **互動式圖表**: 使用 Google Charts 建立動態折線圖
- **資料視覺化**: 將複雜資料轉換為易於理解的視覺圖表
- **響應式設計**: 支援不同螢幕尺寸的顯示

## 🛠️ 技術實現

- **前端**: HTML, CSS, JavaScript
- **後端**: PHP
- **圖表庫**: Google Charts API
- **資料格式**: CSV
- **資料處理**: JavaScript + PHP

## 📁 檔案結構

```
LineChart/
├── week17_p28.html     # 主要顯示頁面
├── week17_p28.php      # 資料處理後端
├── GlobalOilOpenData.csv # 石油開放資料
├── Demo.png            # 功能展示截圖
└── README.md           # 專案說明
```

## 🚀 使用方法

1. 確保 Web 伺服器環境支援 PHP
2. 將專案檔案放置於 Web 伺服器目錄
3. 開啟 `week17_p28.html` 檔案
4. 系統會自動載入 CSV 資料並生成折線圖
5. 可透過圖表進行互動式操作

## 📊 資料來源

- **GlobalOilOpenData.csv**: 全球石油開放資料
- 包含時間序列的石油相關統計資料
- 資料經過 PHP 後端處理後傳送至前端

## 🔧 技術架構

### 後端處理 (PHP)
- 讀取 CSV 檔案
- 解析資料格式
- 轉換為 JSON 格式
- 提供 API 接口

### 前端展示 (JavaScript)
- 接收後端 JSON 資料
- 使用 Google Charts API
- 生成互動式折線圖
- 處理用戶互動事件

## 📈 圖表功能

- **縮放**: 支援圖表縮放功能
- **懸浮提示**: 滑鼠懸浮顯示詳細數值
- **圖例控制**: 可控制資料系列的顯示/隱藏
- **響應式**: 自動適應容器大小
