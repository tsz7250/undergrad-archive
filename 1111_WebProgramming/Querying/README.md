# Querying - 多格式資料查詢系統

## 📖 專案描述

多格式資料查詢系統，支援 CSV、XML 和 URL 等多種資料來源的查詢和篩選功能。使用者可以根據需求進行資料篩選，系統會回傳相應的查詢結果。

## ✨ 功能特色

- **多格式支援**: CSV、XML、URL 資料來源
- **靈活篩選**: 支援多種查詢條件
- **即時查詢**: 快速回傳查詢結果
- **用戶友善**: 直觀的操作介面
- **資料處理**: 高效的資料解析和處理

## 🛠️ 技術實現

- **前端**: HTML, CSS, JavaScript
- **後端**: PHP
- **資料格式**: CSV, XML, URL
- **查詢處理**: PHP + JavaScript

## 🚀 使用方法

### CSV 資料查詢 (ch16_p22)
1. 開啟 `ch16_p22.html`
2. 系統自動載入 CSV 資料
3. 使用篩選條件進行查詢
4. 檢視查詢結果

### XML 資料查詢 (ch16_p36)
1. 開啟 `ch16_p36.html`
2. 系統解析 XML 資料結構
3. 選擇查詢參數
4. 取得篩選後的結果

### URL 資料查詢 (ch16_p45)
1. 開啟 `ch16_p45.html`
2. 輸入或選擇 URL 資料來源
3. 設定查詢條件
4. 執行查詢並查看結果

## 📊 支援的資料格式

### CSV 格式
- 逗號分隔值檔案
- 支援標題列
- 自動欄位識別
- 條件篩選功能

### XML 格式
- 結構化標記語言
- 支援巢狀結構
- 節點查詢功能
- 屬性值篩選

### URL 資料
- 遠端資料來源
- API 接口支援
- 即時資料獲取
- 動態查詢處理

## 🔧 查詢功能

- **條件篩選**: 支援多種比較運算子
- **排序功能**: 依指定欄位排序
- **分頁顯示**: 大量資料分頁處理
- **結果匯出**: 查詢結果可匯出

## 📋 資料範例

- **NPA_TD1.csv**: 區域代碼資料
- **StationFacilityList.xml**: 車站設施清單
- 可自訂資料來源進行測試
