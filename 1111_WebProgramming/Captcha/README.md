# Captcha - 智能驗證碼系統

## 📖 專案描述

智能驗證碼系統，使用圖片分類驗證用戶身份。系統在網頁上隨機顯示5張照片(3張同類別、2張不同類別)，當使用者正確選擇少數類時通過驗證。

## ✨ 功能特色

- **圖片驗證**: 隨機顯示動物圖片（貓、狗、鳥類）
- **智能判斷**: 用戶需識別並選擇少數類別的圖片
- **多次機會**: 提供2次選擇機會
- **安全防護**: IP封鎖機制，防止惡意攻擊
- **自動封鎖**: 單一IP連續3次驗證失敗將被封鎖

## 🛠️ 技術實現

- **前端**: HTML, CSS, JavaScript
- **後端**: PHP
- **安全機制**: IP追蹤與封鎖系統

## 📁 檔案結構

```
Captcha/

├── README.md          # 專案說明

├── cat1.jpg - cat5.jpg    # 貓類圖片素材
└── dog1.jpg - dog5.jpg    # 狗類圖片素材
```

## 🚀 使用方法

1. 開啟 `captcha.html` 檔案
2. 觀察顯示的5張圖片
3. 識別並點選少數類別的圖片（通常是2張）
4. 系統會即時反饋驗證結果
5. 驗證失敗可重試，最多2次機會

## 📋 驗證規則

- 顯示5張圖片：3張同類別 + 2張不同類別
- 用戶需選擇2張少數類別的圖片
- 選擇正確：通過驗證
- 選擇錯誤：提供重試機會
- 連續失敗3次：IP被封鎖

## 🛡️ 安全特性

- IP追蹤機制
- 自動封鎖惡意IP
- 防止暴力破解
- 保護網站安全
