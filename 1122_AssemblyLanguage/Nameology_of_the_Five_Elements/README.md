# Nameology of the Five Elements
## 五格姓名學分析程式

### 專案描述 (Project Description)
本程式使用 RISC-V 組合語言實作傳統中文姓名學分析，根據姓名筆劃數計算三才五格。

### 功能特色 (Features)
- **姓名筆劃輸入** - 輸入姓名各字的筆劃數
- **三才五格計算** - 計算天格、人格、地格、外格、總格
- **命理分析** - 基於傳統姓名學理論進行分析

### 檔案說明 (Files)
- `s1111452_HW2.asm` - RISC-V 組合語言主程式
- `s1111452_HW2_1_demo.png` - 程式執行結果示例 1
- `s1111452_HW2_2_demo.png` - 程式執行結果示例 2
- `README.md` - 本說明文件

### 使用方式 (Usage)
1. 使用 RISC-V 模擬器載入 `.asm` 檔案
2. 依照程式提示輸入姓名各字的筆劃數
3. 程式將計算並顯示三才五格結果

### 三才五格說明 (Five Grids Explanation)
- **天格** - 代表祖運、父母的影響
- **人格** - 代表主運、個人性格
- **地格** - 代表前運、年輕時期運勢
- **外格** - 代表副運、人際關係
- **總格** - 代表後運、中晚年運勢
