# 1122 - 組合語言與計算機組織 

## 課程簡介
此為1122學期組合語言與計算機組織課程的作業與報告程式碼倉庫。

## 程式語言
- **RISC-V Assembly Language**

## 專案列表 (Projects)

### 1. [Combination & Permutation](./Combination&Permutation/)
組合與排列數計算程式
- 計算 mPn (排列)
- 計算 mCn (組合) 
- 計算 m^n (次方)
- 計算 mHn (重複組合)

### 2. [Nameology of the Five Elements](./Nameology_of_the_Five_Elements/)
五格姓名學分析程式
- 輸入姓名筆劃數
- 計算三才五格數值

### 3. [Steiner Trees](./Steiner_Trees/)
史坦納樹演算法實作
- 計算圖形中的最小史坦納樹
- 支援座標點輸入與輸出

## 使用說明
每個專案資料夾內都包含：
- RISC-V 組合語言源碼 (`.asm` 檔案)
- 專案說明文件 (`README.md`)
- 執行結果示例圖片
