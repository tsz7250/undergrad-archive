# Combination & Permutation Calculator
## 組合與排列數計算器

### 專案描述 (Project Description)
本程式使用 RISC-V 組合語言實作組合與排列數學運算。

### 功能特色 (Features)
計算以下數學運算：
- **mPn** - 排列 (Permutation): 從 m 個物件中選取 n 個的排列數
- **mCn** - 組合 (Combination): 從 m 個物件中選取 n 個的組合數  
- **m^n** - 次方 (Power): m 的 n 次方
- **mHn** - 重複組合 (Combination with Repetition): 允許重複的組合數

### 使用方式 (Usage)
1. 使用 RISC-V 模擬器載入 `.asm` 檔案
2. 依照程式提示輸入數值
3. 程式將計算並顯示結果
