# 1142 人工智慧輔助軟體開發課程作品集

此儲存庫包含1142學年度「人工智慧輔助軟體開發」課程的作業和專題報告程式碼。

## 📚 課程概述

本課程探討如何應用先進的人工智慧技術輔助軟體開發生命週期，包括需求分析、系統設計、測試計畫、自動化 CI/CD 以及容器化部署。透過具體專案的實作，實踐軟體工程最佳實務。

## 🛠️ 使用技術

- **程式語言**: C++ 20
- **建置工具**: CMake
- **套件管理**: vcpkg
- **測試框架**: Google Test (GTest)
- **容器化工具**: Docker
- **持續整合**: GitHub Actions (CI)
- **版本控制**: Git (包含 subtree 合併技術)

## 📁 專案結構

### [Project0 - Two Sum](./Project0)
「Two Sum」演算法專案。實作了陣列排序與哈希表兩種方法，並進行複雜度分析與 GTest 驗證，包含 Docker 與 GitHub Actions CI 設定。

### [ProjectB - CSV Mini Database & Query Engine](./ProjectB)
輕量級 CSV 資料庫與查詢引擎。支援高效 CSV 解析（使用 `csv-parser`）、記憶體雜湊索引，並提供類 SQL 的複合條件（`AND`, `OR`）查詢引擎。

## 🚀 快速開始

每個專案都有獨立的 README 文件，請參考各專案目錄中的說明文件了解詳細的建置和使用方法。

通過這些專案，學習和實踐了：
- 演算法設計與時間複雜度分析
- 記憶體索引與複合查詢引擎設計

- 自動化測試與持續整合（CI/CD）流程
