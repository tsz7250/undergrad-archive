# Test Plan (Verification)

## 1. 測試目標

驗證系統實現 SRS 中的所有功能、效能與約束需求，確保各模組協作正確、邊界情況處理得當。

---

## 2. 單元測試 (Unit Tests)

### UT-01: CSV Parser Module
**對應 SRS**：SRS-F001, SRS-C002  
**測試項目**：
- 標準 CSV 解析（逗號分隔、無引號）
- 帶引號欄位解析（包含逗號、換行符）
- 轉義符處理（例如 `\"` 表示引號）
- 空值與缺失欄位處理
- 首行作為列標題的驗證

**預期結果**：解析結果與預期數據完全相同

---

### UT-02: Storage Layer
**對應 SRS**：SRS-F002  
**測試項目**：
- 數據載入與 RowID 賦予
- 列與欄位數量正確性
- 重複載入相同檔案時的清理

**預期結果**：RowID 從 0 連續遞增，與行數相等

---

### UT-03: Hash Index Builder
**對應 SRS**：SRS-F002, SRS-P001  
**測試項目**：
- 單欄索引建立與查詢
- 多欄索引建立
- 重複值索引正確性
- 空值索引處理

**預期結果**：`index[column][value]` 返回的所有 RowID 對應的該欄值均為指定值

---

### UT-04: Query Parser
**對應 SRS**：SRS-F003, SRS-F004  
**測試項目**：
- 基本查詢解析：`SELECT * WHERE column = value`
- 欄位清單解析：`SELECT col1, col2 WHERE ...`
- AND 條件解析與優先級
- OR 條件解析與優先級
- 混合 AND/OR 解析（例如 `A AND B OR C`）
- 比較運算子解析：=, <, >, <=, >=, !=

**預期結果**：生成的 AST 結構正確、運算子優先級遵循標準規則

---

### UT-05: Type Inference
**對應 SRS**：SRS-F005  
**測試項目**：
- 整數欄位推斷
- 浮點數欄位推斷
- 字串欄位推斷
- 混合型別處理（例如大部分為數字，少數非數字）

**預期結果**：推斷型別與實際欄位型別一致

---

### UT-06: Query Execution Engine
**對應 SRS**：SRS-F004, SRS-P001  
**測試項目**：
- 單一條件查詢（=、<、>）
- AND 運算（交集）
- OR 運算（聯集）
- 混合 AND/OR 執行
- 空結果集處理
- 全匹配結果集處理

**預期結果**：執行結果與預期完全相同

---

## 3. 壓力測試 (Stress Tests)

### ST-01: 小規模數據集（10,000 行）
**測試項目**：
- CSV 解析與載入時間
- 索引建立時間
- 基本查詢延遲

**預期結果**：所有操作在毫秒級完成

---

### ST-02: 中規模數據集（100,000 行）
**測試項目**：
- 記憶體使用量
- 複合條件查詢延遲
- 大結果集返回性能

**預期結果**：查詢延遲 < 100ms，記憶體使用有理性邊界

---

### ST-03: 大規模數據集（1,000,000+ 行）
**測試項目**：
- 記憶體映射效果驗證
- 查詢延遲（期望仍為毫秒級）
- 記憶體臨界值測試

**預期結果**：O(1) 查詢效率維持，不出現明顯記憶體溢出

---

## 4. 集成測試 (Integration Tests)

### IT-01: 端到端工作流
**場景**：
1. 載入 CSV 檔案
2. 建立索引
3. 執行多個複合查詢
4. 驗證結果正確性

**預期結果**：全流程無錯誤，結果精確

---

## 5. 測試工具與環境

- **單元測試框架**：Google Test (gtest)
- **性能分析**：內置計時器 (`std::chrono`) 或性能分析工具
- **測試檔案**：小型 CSV 示例 (10-100 行) 及大型測試數據集

---

## 6. 持續整合策略

- **自動化觸發**：每次 Git 提交自動執行全部單元與壓力測試
- **門檻標準**：所有測試必須通過，方可合併至 main 分支
- **覆蓋率目標**：>80% 代碼覆蓋率
