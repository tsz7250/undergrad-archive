# Intended Use / Problem Definition

## 問題定義 (Problem Definition)
「Two Sum」是一個核心的演算法挑戰。給定一個整數陣列 `nums` 和一個目標整數 `target`，目標是找出陣列中兩個整數，使其總合等於 `target`，並回傳這兩個整數的索引值。

本專案旨在提供兩種不同時間複雜度的解法實作：
1. **$O(n \log n)$ 策略**：使用排序與雙指標搜尋。
2. **$O(n)$ 策略**：使用雜湊表 (Hash Table) 以空間換取時間。

## 預期用途 (Intended Use)
本專案的設計目標如下：
- **教育用途**：作為資料結構與演算法課程的範例，展示如何對同一問題採用不同策略並分析其效率（時間與空間複雜度）。
- **效能基準測試**：用於比較在不同資料規模下，排序法與雜湊表法的實際運行效能差異。
- **CI/CD 範例**：展示如何使用 GitHub Actions 自動化 C++ 代碼的編譯與測試流程。
- **容器化部署**：演示如何將 C++ 應用程序封裝於 Docker 容器中。

## 目標對象 (Target Audience)
- 正在學習電腦科學與演算法的學生。
- 準備程式分析面試的工程師。
- 尋求 C++ 專案結構與持續整合 (CI) 實作參考的開發者。
