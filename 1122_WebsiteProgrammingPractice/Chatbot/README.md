# Chatbot - LLM 聊天機器人

## 📖 專案簡介
使用 Python Flask 與 Google Gemini API 製作的智能聊天機器人，提供自然語言對話功能。

## 🛠️ 技術架構
- **後端框架**: Python Flask
- **AI 服務**: Google Gemini API
- **前端**: HTML, CSS, JavaScript

## ✨ 主要功能
- 自然語言對話
- Google Gemini AI 驅動
- 即時回應
- 網頁介面操作

## 🚀 安裝與使用

### 環境需求
- Python 3.7+
- Flask
- Google Gemini API 金鑰

### 安裝步驟
1. 安裝相依套件：
   ```bash
   pip install flask google-generativeai
   ```

2. 設定 API 金鑰：
   - 取得 Google Gemini API 金鑰
   - 在程式中設定 API 金鑰

3. 執行應用程式：
   ```bash
   python app.py
   ```

4. 開啟瀏覽器訪問 `http://localhost:5000`
