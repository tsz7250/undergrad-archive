# LineAndScatter - 折線圖與散點圖

## 📖 專案簡介
使用 Plotly.js 製作的折線圖與散點圖展示專案，展示不同的資料視覺化方式。

## 🛠️ 技術架構
- **前端**: HTML, CSS, JavaScript
- **視覺化函式庫**: Plotly.js
- **圖表類型**: 折線圖、散點圖

## ✨ 主要功能
- 折線圖繪製
- 散點圖展示
- 多資料系列支援
- 互動式圖表操作
- 圖表切換功能

## 🚀 使用方法
1. 開啟 `index.html` 檔案
2. 查看不同類型的圖表展示
3. 與圖表進行互動（縮放、平移、選取等）
4. 修改資料來源測試不同效果

LineAndScatter/

## 📊 圖表特色
- **折線圖**：適合顯示時間序列資料趨勢
- **散點圖**：適合顯示兩變數間的相關性
- **混合圖表**：結合不同圖表類型
- **多系列資料**：同時顯示多組資料

- 動態圖例
- 資料點提示
- 軸標籤自定義
