# HelloLangChain - Google Gemini API 實作

## 📖 專案簡介
使用 Google Gemini API 的基礎實作專案，探索 LangChain 框架與 Google 的生成式 AI 服務整合。

## 🛠️ 技術架構
- **AI 框架**: LangChain
- **AI 服務**: Google Gemini API
- **程式語言**: Python

## ✨ 主要功能
- Google Gemini API 基本調用
- LangChain 框架整合
- 文字生成與處理
- API 回應格式化

## 🚀 安裝與使用

### 環境需求
- Python 3.7+
- LangChain
- Google Gemini API 金鑰

### 安裝步驟
1. 安裝相依套件：
   ```bash
   pip install langchain google-generativeai
   ```

2. 設定 API 金鑰：
   - 取得 Google Gemini API 金鑰
   - 設定環境變數或在程式中配置

3. 執行測試程式：
   ```bash
   python main.py
   ```
