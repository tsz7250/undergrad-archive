# HelloJavaScript - JavaScript 基礎測試

## 📖 專案簡介
JavaScript 基礎功能測試專案，用於驗證和學習 JavaScript 基本語法與功能。

## 🛠️ 技術架構
- **前端**: HTML, CSS, JavaScript
- **用途**: 基礎語法測試與學習

## ✨ 主要功能
- JavaScript 基本語法示範
- 變數與函數測試
- DOM 操作練習
- 事件處理示例

## 🚀 使用方法
1. 開啟 `index.html` 檔案
2. 透過瀏覽器開發者工具查看 JavaScript 執行結果
3. 修改程式碼進行測試與學習

## 📁 檔案結構
```
HelloJavaScript/
├── README.md
├── index.html
├── script.js
└── style.css
```

## 📚 學習重點
