# SimCardCalculator - SIM卡購買天數計算器

## 📖 專案簡介
使用 JavaScript 製作的 SIM 卡購買天數計算器，幫助使用者計算不同方案的最適合購買天數與費用。

## 🛠️ 技術架構
- **前端**: HTML, CSS, JavaScript
- **計算邏輯**: JavaScript 數學運算
- **使用者介面**: 表單與結果展示

## ✨ 主要功能
- SIM 卡方案比較
- 天數與費用計算
- 最佳方案推薦
- 即時計算結果
- 費用明細顯示

## 🚀 使用方法
1. 開啟 `index.html` 檔案
2. 輸入使用天數或預算
3. 選擇不同的 SIM 卡方案
4. 系統自動計算最適合的方案
5. 查看詳細的費用分析

## 💰 計算功能
- **日租方案**：按日計費計算
- **月租方案**：按月計費換算
- **預付方案**：一次性付費分析
- **組合方案**：多種方案混合計算

## 📊 結果展示
- 總費用計算
- 平均日費用
- 方案比較表

- 節費金額顯示
