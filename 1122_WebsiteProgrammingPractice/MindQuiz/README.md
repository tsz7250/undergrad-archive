# MindQuiz - JavaScript 心理測驗

## 📖 專案簡介
使用純 JavaScript 製作的心理測驗應用程式，提供互動式測驗體驗，每頁顯示一題目，使用者選擇後可進入下一題，最後顯示測驗結果。

## 🛠️ 技術架構
- **前端**: HTML, CSS, JavaScript
- **類型**: 單頁應用程式 (SPA)
- **資料處理**: 純前端 JavaScript

## ✨ 主要功能
- 逐題顯示測驗問題
- 多選項答案選擇
- 動態按鈕狀態（開始、下一題、重新開始）
- 結果分析與顯示
- 重新測驗功能

## 🚀 使用方法
1. 開啟 `index.html` 檔案
2. 點擊「開始測驗」按鈕
3. 閱讀題目並選擇答案
4. 點擊「下一題」繼續
5. 完成所有題目後查看結果
6. 可選擇「重新開始」再次測驗

## 📁 檔案結構
```
MindQuiz/
├── README.md
```

## 🎯 測驗流程
1. **開始頁面**：顯示測驗說明與開始按鈕
2. **答題階段**：逐題顯示，收集使用者回答
3. **結果頁面**：分析答案並顯示測驗結果
4. **重新測驗**：清除紀錄，回到開始狀態

## 🔧 按鈕邏輯
- **開始測驗**：初始狀態，開始第一題
- **下一題**：答題過程中，前往下一個問題
- **重新開始**：測驗結束後，重置所有狀態
