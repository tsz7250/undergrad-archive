# 1122 網站程式設計實務 - 作業與專案集合

## 🎯 專案概述
此倉庫包含1122學期「網站程式設計實務」課程的所有作業和報告程式碼，涵蓋多種網站開發技術與實務應用。

## 🛠️ 使用技術
- **前端技術**: HTML, CSS, JavaScript
- **後端技術**: Python (Flask)
- **資料視覺化**: Plotly.js
- **AI/機器學習**: Google Gemini API, LangChain
