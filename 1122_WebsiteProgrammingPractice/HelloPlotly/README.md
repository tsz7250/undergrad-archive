# HelloPlotly - Plotly.js 基礎測試

## 📖 專案簡介
Plotly.js 資料視覺化函式庫的基礎測試專案，用於學習和驗證 Plotly.js 的基本功能。

## 🛠️ 技術架構
- **前端**: HTML, CSS, JavaScript
- **視覺化函式庫**: Plotly.js
- **資料處理**: JavaScript

## ✨ 主要功能
- Plotly.js 基本圖表繪製
- 互動式圖表展示
- 資料視覺化測試
- 圖表配置與客製化

## 🚀 使用方法
1. 開啟 `index.html` 檔案
2. 瀏覽器會載入 Plotly.js 並顯示測試圖表
3. 與圖表進行互動（縮放、平移等）
4. 修改程式碼測試不同圖表類型
