# ClubCourse - 自動排課系統

## 📖 專案簡介
使用 JavaScript 製作自動排課系統，只要輸入開始課號，就可以自動排課。每增加一個動課節數，課號會自動累加。另外課號內容輸入，就可以自動編課。

## 🛠️ 技術架構
- **前端**: HTML, CSS, JavaScript
- **核心功能**: 自動化課程編排邏輯

## ✨ 主要功能
- 自動排課功能
- 課號自動累加
- 課程內容自動編排
- 簡潔直觀的使用介面

## 🚀 使用方法
1. 開啟 `index.html` 檔案
2. 輸入起始課號
3. 系統將自動進行排課
4. 根據需要調整課程內容
