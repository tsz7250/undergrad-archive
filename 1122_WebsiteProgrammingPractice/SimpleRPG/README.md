# SimpleRPG - JavaScript RPG 小遊戲

## 📖 專案簡介
使用 JavaScript 製作的 RPG 小遊戲，實現基本的角色扮演遊戲機制，包含角色移動、碰撞偵測、目標達成等核心功能。

## 🛠️ 技術架構
- **前端**: HTML5 Canvas, CSS, JavaScript
- **遊戲引擎**: 純 JavaScript 實作
- **圖形處理**: Canvas 2D API

## ✨ 遊戲功能
- **角色移動**：可控制主角在遊戲世界中移動
- **邊界偵測**：角色不會走出遊戲範圍
- **碰撞判斷**：可偵測與人物、障礙物的碰撞
- **終點判斷**：可判斷是否到達終點
- **方向圖案**：主角圖案會隨移動方向改變

## 🚀 使用方法
1. 開啟 `index.html` 檔案
2. 使用鍵盤方向鍵控制角色移動
3. 避開障礙物，與 NPC 互動
4. 努力到達遊戲終點
5. 完成後可重新開始遊戲

## 🎮 操作控制
- **方向鍵**：角色移動（上下左右）
- **空白鍵**：與 NPC 互動
- **ESC 鍵**：暫停/繼續遊戲
- **R 鍵**：重新開始遊戲

## 🗺️ 遊戲元素
- **主角**：玩家控制的角色
- **NPC**：非玩家角色，可互動
- **障礙物**：阻擋移動的物件
- **終點**：遊戲目標位置
- **背景**：遊戲世界環境

## 🔧 技術特色
- **碰撞偵測系統**：精確的物理碰撞判斷
- **方向感知**：角色圖像隨移動方向變化
- **邊界限制**：防止角色移出遊戲區域
- **狀態管理**：遊戲進度與狀態追蹤
