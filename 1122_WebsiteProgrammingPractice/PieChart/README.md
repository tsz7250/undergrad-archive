# PieChart - 圓餅圖製作

## 📖 專案簡介
使用 Plotly.js 製作的圓餅圖展示專案，適合展示資料的比例分布與組成結構。

## 🛠️ 技術架構
- **前端**: HTML, CSS, JavaScript
- **視覺化函式庫**: Plotly.js
- **圖表類型**: 圓餅圖、環形圖

## ✨ 主要功能
- 標準圓餅圖
- 環形圖展示
- 資料標籤顯示
- 互動式切片選取
- 動態資料更新

## 🚀 使用方法
1. 開啟 `index.html` 檔案
2. 查看圓餅圖的資料分布
3. 點擊圖表切片查看詳細資訊
4. 修改資料來源客製化圖表

PieChart/

## 📊 圖表特色
- **比例展示**：清楚顯示各項目佔比
- **顏色分組**：使用不同顏色區分類別
- **標籤顯示**：支援數值與百分比標籤
- **互動功能**：點擊、懸停效果

## 🎨 視覺化功能
- 切片分離效果
- 自定義顏色配置
- 圖例顯示
- 數據標籤格式化
- 響應式佈局
