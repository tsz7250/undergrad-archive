# RandomSelector - 亂數選擇器

## 📖 專案簡介
使用 JavaScript 製作的亂數選擇器，能夠隨機選擇項目並輸出對應的文字描述與相關圖片。

## 🛠️ 技術架構
- **前端**: HTML, CSS, JavaScript
- **核心功能**: Math.random() 亂數生成
- **媒體處理**: 圖片動態載入

## ✨ 主要功能
- 隨機項目選擇
- 文字結果顯示
- 對應圖片展示
- 動畫過渡效果
- 重複選擇功能

## 🚀 使用方法
1. 開啟 `index.html` 檔案
2. 點擊「開始選擇」或「隨機選擇」按鈕
3. 系統將隨機選出一個項目
4. 查看選擇結果的文字描述與圖片
5. 可重複進行選擇
