# BigFib HW2 - 標準二元費波那契數列

## 🔢 專案概述

在沒有使用大數的情況下，實作二元數的費波那契數列 (Binary Fibonacci Sequence)，並提供自訂的輸入運算子。

## 📐 數學公式

本專案實作的二元費波那契數列遵循以下數學公式：

```
F(N).X = F(N-1).X + F(N-2).X
F(N).Y = F(N-1).X + F(N-2).X + F(N-1).Y × F(N-2).Y
```

## ✨ 主要功能

### 🧮 標準數值運算
- 使用標準數據型別進行費波那契數列計算
- 適用於中小型數值範圍

### ⌨️ 自訂輸入運算子
- 實作 `operator >>` 運算子重載
- 讓使用者可以直接輸入二元數
- 提供友善的使用者介面

1. 直接執行編譯好的 `s1111452_HW2.exe`
2. 或重新編譯 `s1111452_HW2.cpp` 檔案
3. 使用自訂的輸入運算子輸入二元數
4. 查看費波那契數列計算結果

## 🎯 設計重點

### 📥 輸入運算子設計
- 重載 `>>` 運算子提供直觀的輸入方式
- 支援二元數的格式化輸入

### 🔢 數值範圍
- 適用於標準整數範圍內的計算
- 在數值不會溢位的情況下提供高效運算
