# BigFib HW3 - 大數二元費波那契數列

## 🔢 專案概述

使用大數運算實作二元數的費波那契數列 (Binary Fibonacci Sequence)，支援超大數值的精確計算。

## 📐 數學公式

本專案實作的二元費波那契數列遵循以下數學公式：

```
F(N).X = F(N-1).X + F(N-2).X
F(N).Y = F(N-1).X + F(N-2).X + F(N-1).Y × F(N-2).Y
```

## ✨ 主要特色

### 🔢 大數支援
- 支援任意精度的大數運算
- 突破標準數據型別的限制
- 適用於計算大型費波那契數列

### 🧮 二元結構
- 每個費波那契數包含 X 和 Y 兩個分量
- 支援複雜的數學運算關係
