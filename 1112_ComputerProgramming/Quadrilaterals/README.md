# Quadrilaterals 四邊形類別設計

## 📐 專案概述

本專案實作四邊形相關的物件導向類別系統，使用 Point2 類別來儲存座標點資訊。

## 🏗️ 類別架構

### 📍 座標系統
- **Point2**: 用於儲存二維座標點的基礎類別

### 🔷 四邊形類別層次
- **myQuadrilateral**: 四邊形基礎類別
- **myTrapezium**: 梯形類別
- **myParallelogram**: 平行四邊形類別  
- **myRectangle**: 矩形類別
- **mySquare**: 正方形類別

## ✨ 主要功能

每個四邊形類別都包含其對應的成員函數 (member functions)，提供：
- 幾何屬性計算
- 形狀驗證
- 座標操作
