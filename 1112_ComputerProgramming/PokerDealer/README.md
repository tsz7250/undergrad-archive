# PokerDealer 撲克牌發牌系統

## 🃏 專案概述

本專案基於鏈結串列 (Linked List) 建立完整的撲克牌遊戲系統，包含撲克牌儲存、洗牌、發牌與牌型判定功能。

## 🏗️ 類別設計

### 🎴 撲克牌系統
- **Card**: 撲克牌基礎類別
- **DeckOfCards**: 撲克牌牌組類別
  - 可儲存 52 張撲克牌
  - 提供洗牌 (shuffle) 功能
  - 提供發牌 (deal) 功能

### 🤲 手牌管理
- **Hand**: 手牌類別
  - 從 DeckOfCards 獲取一手牌 (五張)
  - 判定牌組所屬的類別 (牌型)

## 🎯 遊戲流程

### 🔀 初始設定
- 程式開始時會隨機排序 52 張牌

### 🎮 遊戲操作
- 每次按 Enter 鍵依序抽取 5 張牌
- 總共可以抽取 10 次 (共 50 張牌)
- 系統會自動判定每手牌的牌型

## 🚀 使用方式

1. 編譯主程式檔案
2. 執行程式開始遊戲
3. 按 Enter 鍵進行發牌
4. 查看系統判定的牌型結果
