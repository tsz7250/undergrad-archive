# 1112 程式設計(二) - Computer Programming II

## 📋 課程概述

此為1112 程式設計(二)課程的作業與報告程式碼集合。

## 🛠️ 技術規格

- **程式語言**: C++ 
- **程式設計範式**: 物件導向程式設計 (OOP)

## 📁 專案結構

### 作業項目

| 專案 | 說明 |
|------|------|
| [BigFib](./BigFib/) | 大數運算的費波那契數列實作 |
| [CipherMachine](./CipherMachine/) | 字串處理與編碼機器實作 |
| [Graph](./Graph/) | 圖形容器設計與路徑演算法 |
| [PokerDealer](./PokerDealer/) | 撲克牌發牌系統實作 |
| [Quadrilaterals](./Quadrilaterals/) | 四邊形類別設計與點座標系統 |

## 🚀 使用方式

每個子專案都包含獨立的README文件，請參考各別專案的說明文件以了解詳細的編譯與執行方式。

## 📝 開發環境

- C++ 編譯器支援
- 標準C++物件導向程式設計功能
