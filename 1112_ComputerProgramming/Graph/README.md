# Graph 容器設計 - 圖形演算法實作

## 📊 專案概述

本專案實作圖形容器設計，包含路徑搜尋 (PATH) 與最小生成樹 (SPANNING TREE) 演算法。

## ✨ 主要功能

### 🛤️ 路徑搜尋 (Path Finding)
- 根據輸入檔案中的資訊 (多組起點與終點)
- 輸出對應連接起點與終點的路徑到 `paths.txt` 檔案

### 🌳 最小生成樹 (Spanning Tree)
- 根據輸入檔案中指定的根節點 (root)
- 以此節點為基準輸出任意一個生成樹到 `tree.txt` 檔案

## 📁 檔案結構

```
Graph/
├── README.md          # 本說明文件
├── main.cpp          # 主程式檔案
└── graph0_v2.txt     # 輸入檔案範例
```

## 🚀 使用方式

1. 準備圖形資料輸入檔案
2. 編譯並執行主程式
3. 查看輸出的路徑檔案 `paths.txt` 與生成樹檔案 `tree.txt`

## 📝 輸出檔案

- **paths.txt**: 包含所有查詢路徑的結果
- **tree.txt**: 包含從指定根節點生成的生成樹結構
