# CipherMachine 編碼機器 - 字串處理與加密系統

## 🔐 專案概述

本專案實作字串處理類別與小型編碼機器系統，提供完整的加密解密功能。

## 🏗️ 類別設計

### 📝 字串處理
- **mString**: 處理字串的專用類別

### 🔒 編碼機器
- **mCipher**: 小型編碼機器類別

## 📋 編碼解碼方法

詳細的編碼解碼方法與範例請參考 [`Test_Case.txt`](./Test_Case.txt) 檔案。

### 🔧 對應表系統
- **Rotor**: 旋轉器對應表
- **Reflector**: 反射器對應表

## ⚙️ 操作模式

### 🔒 編碼 (Encode)
- 依序輸入原始文字
- 得到對應的加密內容

### 🔓 解碼 (Decode)  
- 依序輸入加密過的字元
- 得到原始文字

## 📊 運作模式

### 🔄 動態模式
- **重設功能**: `reset()` 函數重設編碼機狀態
- **狀態變化**: 每次輸入一個字元，Rotor 和輸入輸出的對應就會改變
- **規律性**: 變動有規律，解碼時重設旋轉量後依序輸入密文即可得到原始輸入

### ⚡ 靜態模式
- **穩定輸出**: 設定好機器後，每個輸入會穩定得到固定輸出
- **簡易解碼**: 解碼只要將密文再輸入一次即可
